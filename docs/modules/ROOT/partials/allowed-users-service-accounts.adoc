=== Service accounts

Kubernetes service accounts can also be granted access through `allowedUsers`.
A service account authenticates with the username `system:serviceaccount:<namespace>:<name>`, so use that form in the list:

[source,yaml]
----
spec:
  parameters:
    security:
      allowedUsers:
        - system:serviceaccount:prod-app:log-reader # <1>
      allowedGroups:
        - system:serviceaccounts:prod-tools # <2>
----

<1> Grants the service account `log-reader` in namespace `prod-app` limited access to the instance namespace, for example to read the logs of the service pods.
<2> Grants every service account in namespace `prod-tools` limited access to the instance namespace.

[NOTE]
====
The entries aren't validated.
A typo in the username or namespace name results in no access, without an error.
====
